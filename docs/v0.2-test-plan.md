# Teste da v0.2.0-dev no aparelho

Esta versão **não é uma release**. Build CI usa chave debug temporária;
ela pode ter assinatura diferente da instalação anterior.

## Antes
1. Mantenha outro launcher instalado e configurado como alternativa para voltar à tela inicial caso ocorra um crash.
2. Se o Android disser "App não instalado" por conflito de assinatura, desinstale a versão debug anterior — isso apaga favoritos daquela instalação.
3. Instale o APK `jj-launcher-debug` do workflow associado ao PR #3.

## Checklist funcional
- [ ] Ao abrir, a faixa **Defina como tela inicial** aparece se o launcher não for padrão.
- [ ] Ao tocar **Ativar**, o Android oferece a seleção de launcher (ou configurações equivalentes).
- [ ] Após escolher JJ Launcher, pressionar Home retorna a tela inicial do JJ Launcher.
- [ ] Deslizar para cima abre a gaveta; ao arrastar lentamente, ela acompanha o dedo.
- [ ] A gaveta rola sem travamentos perceptíveis; procurar e abrir apps funciona.
- [ ] Pressionar Voltar fecha a gaveta; **Opções** abre os links de padrão e atualizações.
- [ ] Manter pressionado um app adiciona/remove o favorito do dock.
- [ ] Abrir outro app e voltar não provoca repintura custosa de todos os ícones.
- [ ] Alternar papel de parede e tema do sistema não quebra contraste da tela inicial.
- [ ] Instalar ou remover um aplicativo atualiza a gaveta após o evento de pacote.

## Avaliação de desempenho
Compare, no **mesmo aparelho**, a versão anterior e esta; ao entrar em uma longa lista,
role do início ao fim algumas vezes. Faça a avaliação também com um APK de release
**assinado de teste**, porque builds debug não representam fielmente o desempenho final.
Registre engasgos observados, fabricante, modelo, versão Android e, quando disponível,
dados de frames via Android Studio Profiler / Perfetto.

**Critério:** desempenho deve ser comprovado em aparelho real antes de publicar.
