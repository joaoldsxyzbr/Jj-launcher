# JJ Launcher v0.1.0 — primeira versão experimental

Primeira versão instalável do JJ Launcher, um launcher Android open source, discreto e minimalista.

## Novidades

- Tela inicial com relógio, data e papel de parede do dispositivo.
- Dock de até cinco favoritos, configuráveis por toque prolongado.
- Gaveta de aplicativos com ícones reais do Android.
- Busca de apps que ignora diferenças de acentuação e maiúsculas.
- Gesto para abrir a gaveta, botão Voltar e abertura direta dos aplicativos.
- Opção para definir o JJ Launcher como tela inicial padrão.
- Atalho **Atualizações** para a página de versões do GitHub.
- Preferências armazenadas somente no dispositivo; sem anúncios, telemetria ou permissão de internet.

## Instalação e futuras atualizações

Instale o **APK release assinado** anexado a esta versão, quando publicado. Acompanhe novas versões com [Obtainium](https://obtainium.imranr.dev/) usando a fonte `https://github.com/joaoldsxyzbr/Jj-launcher`.

Para que futuras versões sejam instaladas por cima da atual sem perder os favoritos, a chave de assinatura e o ID `dev.jj.launcher` serão mantidos. Não instale um APK *debug* do CI se pretende atualizar pelo canal oficial.

## Limitações desta versão

Esta é uma versão experimental. Ainda não existem widgets, pastas, múltiplas páginas ou integração com a tela de apps recentes. A fluidez e o funcionamento como launcher padrão precisam de validação em aparelhos reais.
